# 📚 Minha Biblioteca

Sistema pessoal de catalogação de livros.

## Recursos
- Autenticação (JWT + bcrypt)
- CRUD de livros com capas
- Categorias, tags e filtros avançados
- Dashboard com estatísticas
- Modo escuro
- Export CSV
- Backup em JSON (com imagens em Base64)
- PWA (instalável no celular)

## Stack
- Node.js + Express
- PostgreSQL (Supabase)
- Tailwind CSS (CDN)

## Como rodar localmente
1. `npm install`
2. Crie um arquivo `.env` com `DATABASE_URL=...`
3. `node server.js`
4. Abra http://localhost:3000
